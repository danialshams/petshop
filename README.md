# PetFood — فروشگاه نمایشی محصولات پت

بازطراحی کامل بر اساس رنگ‌ها و ساختار صفحه Pet Food Website Design در Behance: هیروی بنفش و موج نارنجی، دسته‌های تصویری گرد، بنرهای آبی و سبز، محصولات و بخش‌های پایین صفحه. کلیه متون فارسی و جهت صفحه RTL است.

- Next.js 16, React 19, no UI component dependencies.
- تصاویر اختصاصی حیوانات در `public/images`, بهینه شده WebP و بدون لینک خارجی.
- لودر سگ از فایل شفاف انیمیشنی قبلی `public/images/dog-barking-transparent.webp` با یک دور کامل ۶ ثانیه‌ای؛ شش ردپای متحرک با محوشدن کامل.
- منوی موبایل با پنجه سگ سمت راست و باز شدن از راست.
- جست‌وجو، دسته‌بندی محصولات، علاقه‌مندی و سبد نمایشی.
- پرداخت واقعی، سرور و موجودی کالا هنوز متصل نیستند؛ این نسخه برای نمونه‌کار است.

## Running

`npm install` سپس `npm run dev`

## Validate

`npm run build`
