# PetFood — Next.js 16 • فارسی / RTL

بازطراحی بر مبنای رفرنس منتخب Pet Food با رنگ‌های بنفش، آبی، سبز و نارنجی.

## اجرا
```bash
npm install
npm run dev
npm run build
```

## امکانات این نسخه
- هشت تصویر واقعیِ تولیدشده و بهینه WebP برای محصولات در `public/images/products`
- تصاویر حیوانات در مسیر محلی `public/images`، بدون وابستگی به منابع خارجی
- اتصال تصویر سگ هیرو به لبه موج نارنجی، همراه با سه وسیله واقعی پت که با GSAP شناورند
- GSAP ScrollTrigger برای ورود تیترها، کارت‌های محصولات، بنرها و پارالاکس تصاویر
- ردپاهای سگ، گربه و خرگوش در نقاط مختلف، با فاصله‌های متغیر و محوشدن کامل
- لودر سگ با شش ردپای سریع‌تر، منوی موبایل پنجه‌ای از راست با رنگ‌های متنوع
- جست‌وجو، فیلتر محصولات، علاقه‌مندی‌ها و سبد خرید نمایشی

**وضعیت:** بسته کد این اصلاحات آماده است؛ تا زمان دریافت پاسخ موفق از GitHub و نصب وابستگی‌ها، نسخه جدید روی `main` منتشر نشده و بیلد Next.js تأیید نشده است.
