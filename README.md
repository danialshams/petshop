# کوزی‌پاوز | CozyPaws

دموی فارسی راست‌به‌چپ فروشگاه محصولات حیوانات خانگی با Next.js و React.

## اجرای محلی

```bash
npm install
npm run dev
```

## آزمون

```bash
npm run build
```

## وضعیت دارایی‌ها

طرح صفحه اول بر اساس چیدمان مرجع CozyPaws ساخته شده است. عکس‌های فعلی **جایگزین‌های موقت** از Unsplash هستند؛ ابزار تولید عکس اختصاصی متصل فعلاً اعتبار ندارد. تصاویر اصلی باید بعداً تولید و در `public/images` قرار بگیرند. محصولات و قیمت‌ها برای دمو ساخته شده‌اند، درگاه پرداخت یا پایگاه داده متصل نیست.

لودر فعلی با SVG سگ متحرک و شش ردپای یکی‌درمیان ساخته شده است. فایل `Dog_Barking_Clean.mp4` هنوز به‌عنوان فایل باینری داخل مخزن بارگذاری نشده و در این نسخه از ویدیو استفاده نشده است.

## امکانات دموی اولیه

- هوم‌پیج RTL، ریسپانسیو
- بخش دسته‌بندی، محصولات، بنر، مزایا و فوتر
- فیلتر، جست‌وجوی محصول، علاقه‌مندی، افزودن به سبد و تغییر تعداد
- لودر سگ و شش ردپای متحرک، و حالت کم‌تحرک برای کاربران حساس به حرکت
- CI خودکار برای بیلد قبل از ادغام
